# GOADv2 — colección BloodHound de ejemplo

Colecciones SharpHound v2.3.3 del laboratorio GOADv2 (dominios ESSOS, NORTH y
SEVENKINGDOMS), tomadas del repositorio `m4lwhere/Bloodhound-CE-Sample-Data`
(licencia Unlicense, ver `LICENSE`). Es un laboratorio público con nombres
ficticios; no contiene datos de clientes.

Se usa para verificar el oráculo dinámico sobre la estructura de un AD real
(`graphhunter_defensa/test_ad.py`, `graphhunter_defensa/bench_ad.py`).
