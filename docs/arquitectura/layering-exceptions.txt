# Layering exceptions — whitelist of core -> platform dependencies.
#
# Each non-comment, non-empty line is a dependency that check-layering.sh
# will accept without failing. Format:
#
#     <core-crate-dir> -> <platform-crate-dir>
#
# e.g.
#     core/graph-engine -> platform/sources
#
# Paths are relative to the repo root. Comments (#) and blank lines are
# ignored. Anything NOT listed here is rejected.
#
# Adding an entry = committing to a reason. Document it in an ADR before
# adding. Rationale for the current entries:
#
#   core/graph-engine -> platform/sources
#     The LogSource trait + Azure connectors were lifted into platform/
#     per F2.11 but the core graph engine re-exports them under the old
#     `sources::` path to avoid a flag-day rewrite of ingest adapters.
#     The trait is defined in platform/ and depended-on by core via
#     dependency inversion (the trait itself, not any concrete type).
#     Tracking removal: ADR-002 follow-up.
#
#   core/graph-engine -> platform/dsl
#     The DSL parser + types/hypothesis modules were lifted out per F2.12
#     but core re-exports them under the original `types::` / `hypothesis::`
#     paths so the ~140 internal references keep resolving.
#     Tracking removal: ADR-005 follow-up.

core/graph-engine -> platform/sources
core/graph-engine -> platform/dsl
