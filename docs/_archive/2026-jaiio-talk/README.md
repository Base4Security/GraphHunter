# JAIIO 2026 — Utilidades de conferencia

Material asociado a una charla en las JAIIO 2026 (Jornadas Argentinas de Informática e Investigación Operativa), creado a comienzos de mayo 2026.

Estos archivos eran utilidades one-off para preparar el deck/demo de la charla — no son parte del producto GraphHunter ni se ejecutan en CI/build:

- `jaiio_inspect.py` — inspector ad-hoc de algún dataset/output para el slide.
- `jaiio_format_fix.py` / `jaiio_fix_gen.py` / `jaiio_update.py` — utilidades de formateo/edición sobre material de la charla.
- `jaiio_before.md` / `jaiio_after.md` — notas o snippets "antes/después" referenciados en la presentación.

Archivados aquí en el sanitizado post-book-v1.0.0 para preservar el material sin ensuciar `scripts/` activo.
