\section{Patrones comunes}

\begin{itemize}
    \item Cada request DTO que toca estado de sesión lleva
        \code{session: Option<SessionHandle>}. La fachada
        resuelve \code{None} a la sesión actual.
    \item Los errores fluyen vía \code{Result<T, ApiError>} (ver
        \filepath{graph\_hunter\_api/src/error.rs}), que cada
        transport mapea a su propio envelope (HTTP 400/404/500,
        Tauri \code{CommandError}, texto de error MCP).
    \item Las variantes de enum usan \code{\#[serde(tag =
        "kind")]} para variantes struct; las variantes newtype
        se serializan como su string Display plano (una
        limitación de serde que documentamos en el test de
        roundtrip de errores del
        Capítulo~\ref{ch:parity-harness}).
\end{itemize}

\section{Invariantes de forma}

La \emph{Fase A} del arnés de paridad fija el conjunto de
claves de cada DTO: un rename cambia silenciosamente el JSON
enviado al wire, y dos transports construidos sobre la misma
fachada seguirían en desacuerdo si uno hubiera cacheado una
copia vieja del DTO.
