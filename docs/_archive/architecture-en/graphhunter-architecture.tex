\chapter*{Preface}
\addcontentsline{toc}{chapter}{Preface}

This document describes the architecture and algorithms of
GraphHunter, a temporal-graph threat-hunting engine. The style is
modelled on \emph{Introduction to Algorithms} (Cormen, Leiserson,
Rivest, Stein — ``CLRS''): each algorithm is presented as formal
pseudocode with line numbers, followed by a derivation of its time
and space complexity and, where the invariants aren't obvious, a
correctness argument.

The reference is internal: its purpose is to let a future maintainer
(or the author, six months from now) understand \emph{why} the
engine is shaped the way it is without reading every source file.
Every chapter ends with an \emph{In the code} block giving
\texttt{file:line} pointers so readers can drop into the Rust
implementation on any point of interest.

Parts I--III are fleshed out in this revision. Parts IV--VI (ingest
pipeline, extension seams, transport layer) ship as stubs with
structures and file references but without full pseudocode; the
intent is to expand them chapter-by-chapter in follow-up revisions.
