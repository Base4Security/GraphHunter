\section{Common patterns}

\begin{itemize}
    \item Every request DTO that touches session state embeds
        \code{session: Option<SessionHandle>}. The façade resolves
        \code{None} to the current session.
    \item Errors flow via \code{Result<T, ApiError>} (see
        \filepath{graph\_hunter\_api/src/error.rs}) which every
        transport maps into its own envelope (HTTP 400/404/500,
        Tauri \code{CommandError}, MCP tool error text).
    \item Enum variants use \code{\#[serde(tag = "kind")]} for
        struct variants; newtype variants are serialised as their
        plain string display (a serde limitation we documented in
        Chapter~\ref{ch:parity-harness}'s error-roundtrip test).
\end{itemize}

\section{Shape invariants}

The parity harness's \emph{Phase A} pins every DTO's key set:
a rename silently changes the JSON sent over the wire, and two
transports built on the same façade would still disagree if one
had cached a stale DTO copy.
