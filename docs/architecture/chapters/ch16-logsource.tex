\chapter{The \code{LogSource} Trait}
\label{ch:logsource}

\begin{note}
This chapter is a stub. The \code{LogSource} trait is the bottom
layer of the streaming ingest pipeline: each implementation
represents one external data producer (a Microsoft Sentinel
workspace, a Defender XDR tenant, an Azure Data Lake blob source).
A full walkthrough of the polling lifecycle --- \code{poll\_since}
resumption semantics, cancellation, watermark monotonicity,
backoff and quota interactions --- is deferred to a follow-up
revision.
\end{note}

\section{Structure}

\begin{lstlisting}[style=rust]
#[async_trait]
pub trait LogSource: Send + Sync {
    fn source_id(&self) -> &str;
    fn kind(&self) -> SourceKind;
    fn available_tables(&self) -> &[&'static str];
    async fn check_auth(&self) -> Result<(), SourceError>;
    async fn query_scoped(
        &self,
        scope: QueryScope,
        cancel: CancellationToken,
    ) -> Result<ChunkStream, SourceError>;
    async fn poll_since(
        &self,
        table: &str,
        watermark: Watermark,
        cancel: CancellationToken,
    ) -> Result<PollStream, SourceError>;
}
\end{lstlisting}

A \code{RawChunk} is a \code{Bytes}-backed response fragment
carrying \code{source\_id}, \code{table}, \code{fetched\_at}, and
an optional \code{watermark\_candidate} the source suggests be
persisted after successful parse.
