\section{Trait}

\begin{lstlisting}[style=rust]
pub trait LogParser: Send + Sync {
    fn parse(&self, data: &str) -> Vec<ParsedTriple>;
    fn parse_rows(&self, rows: &[serde_json::Value]) -> Vec<ParsedTriple> {
        // Default: serialize rows back to a JSON array and delegate.
    }
}

pub type ParsedTriple = (Entity, Relation, Entity);
\end{lstlisting}

The \code{parse\_rows} override exists to short-circuit the
``JSON $\to$ string $\to$ JSON'' round-trip for parsers that
already consume the \code{serde\_json::Value} shape (notably
\code{SentinelJsonParser}).

\section{Parser dispatch}

The engine does not do format auto-detection in the matcher path;
instead, the ingest façade (\code{graph\_hunter\_api}) picks a
parser per \code{RawChunk.encoding} (Json / Jsonl / Parquet) plus
per-source registration. The \code{preview} family
(\filepath{graph\_hunter\_core/src/preview.rs},
\filepath{field\_preview.rs}) lets the UI sniff a file and suggest
a mapping before committing to ingest.
