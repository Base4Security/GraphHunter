# Decisiones (ADRs lite)

Este directorio contiene **Architecture Decision Records** en formato informal
pero persistente. Cada decisión queda documentada con su contexto, las
alternativas evaluadas y la motivacion del camino elegido, de modo que futuros
contribuyentes puedan reconstruir el "por que" sin tener que arquear sobre el
historial de commits ni leer hilos de PRs cerradas. Los archivos se nombran
`YYYY-MM-DD-<slug>.md` y se anaden conforme se toman decisiones que afectan
arquitectura, licenciamiento, dependencias externas o procesos de release.
